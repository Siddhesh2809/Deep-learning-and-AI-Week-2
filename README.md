# Mini Project 2: Handwritten Digit Classifier

This project implements a Fully Connected Neural Network (FCNN) using PyTorch to classify handwritten digits from the MNIST dataset (0-9).

## 🚀 Features
- Predicts digits from the MNIST dataset.
- Displays sample predictions.
- Reports overall test accuracy and generates a Confusion Matrix.
- Performs error analysis on incorrect predictions.

## 🛠️ Tech Stack
- **Python**
- **PyTorch & Torchvision**
- **Scikit-Learn**
- **Matplotlib & Seaborn**

- **Test Accuracy:** ~97% - 98%
